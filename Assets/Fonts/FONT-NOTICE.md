# Cooking HUD font

`NotoSansSC-CookingSubset.ttf` is a reduced character subset of Noto Sans SC,
used by the TextMeshPro cooking HUD. Noto fonts are distributed under the
SIL Open Font License 1.1: https://openfontlicense.org

The subset contains ASCII, the check mark, and the Chinese characters used by
the current cooking operation labels. Regenerate or replace it when adding new
Chinese UI copy.
