# 2D 迁移备忘

状态：方案讨论，尚未实施。当前可玩的 `GameDemo` 仍使用 3D 占位模型和透视相机；本文件不代表完整游戏的目标架构已经确定。

## 项目选择

在现有 Unity 项目中复制 `GameDemo`，建立独立的 `GameDemo2D` 场景，保留原场景供对照。不需要为了 2D 表现新建项目。现有 `CookingSession`、菜谱配置、输入、计时和屏幕空间 HUD 可以继续使用；先替换相机、工位和角色的场景表现，再调整动画片段。

`CookingDemoBuilder` 当前依赖 3D 场景层级与 `CharacterVisual` 占位物。创建 2D 场景时不能直接用它重建场景，后续应按实际 2D 层级调整生成逻辑，或手动配置新场景。

## 包与渲染

当前项目使用 Unity 2022.3，已安装 URP、Input System 和 UI，并启用 Physics 2D、Tilemap 模块。普通 Sprite 显示和现有 Animator 动画可先在当前项目试做，不需要一次安装 2D 模板的全部包。

| 需求 | 按需添加或配置 |
| --- | --- |
| Sprite 切图与编辑 | 2D Sprite |
| Sprite 骨骼动画 | 2D Animation |
| 像素画清晰缩放 | 2D Pixel Perfect |
| 分层 PSB 美术文件 | 2D PSD Importer |
| 2D 地图或形状地形 | 2D Tilemap Editor / 2D SpriteShape |
| 2D 灯光 | 为现有 URP 配置 2D Renderer |

第一步只做普通 Sprite 场景；确认美术形式后再选择相应包。若要同时保留原 3D 场景，配置 2D Renderer 时需检查两个场景各自使用的渲染器。

参考：[Unity 2022.3：2D 游戏的初始设置](https://docs.unity3d.com/cn/2022.3/Manual/Quickstart2DSetup.html)。
